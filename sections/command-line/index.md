The shell is the program that reads the commands you type and runs them. In this section you'll learn the anatomy of a command, then practice the two skills you'll use constantly: moving around the file system, and combining small commands into useful pipelines.

This section uses the `course` folder you created in [Set Up Your Workspace]({{ '/sections/getting-started/setup/' | relative_url }}).
