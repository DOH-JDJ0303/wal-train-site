## Why the command line?

Most bioinformatics tools are built to run from a terminal. Learning a handful of commands lets you:

- **Work with files that are too large** to open in a spreadsheet or text editor
- **Run analysis tools** that don't have a graphical interface
- **Repeat your work exactly**, because every step is written down as a command
- **Automate** tasks that would otherwise take hours of clicking

## How this course is organized

The course is divided into three sections. Each one starts with a short lecture like this one and continues with hands-on activities:

| Section | You will… |
|---------|-----------|
| **1. Getting Started** | Set up your computer and download the course data |
| **2. The Command Line** | Move around the file system and combine commands with pipes |
| **3. Working with Sequence Data** | Inspect and summarize a FASTQ file of sequencing reads |

Sections build on each other, so work through them in order. The **Next** link at the bottom of every page always points to the next item in the course.

## How activities work

Activities are a series of numbered steps. Most steps ask you to run a command in your terminal — commands appear in dark **Terminal** boxes with a **Copy** button:

```bash
echo "Hello, course!"
```

Some steps show what you should see afterwards, in a dashed **Expected output** box:

```text
Hello, course!
```
{: .output}

When you finish a step, tick its checkbox. Your progress is saved in your browser, and completed items get a check mark in the sidebar.

> Typing commands yourself, rather than copying them, helps you remember them. Use the Copy button when a command is long or easy to mistype.
{: .tip}
