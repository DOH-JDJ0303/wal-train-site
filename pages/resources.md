## Tools used in the activities

| Tool | Used for |
|------|----------|
| [NCBI Datasets](https://www.ncbi.nlm.nih.gov/datasets/) | Downloading genome assemblies by accession |
| [FastANI](https://github.com/ParBLiSS/FastANI) | Average nucleotide identity (ANI) between genomes |
| [GAMBIT](https://github.com/gambit-suite/gambit) | Species identification against a curated reference database |
| [ShigaPass](https://github.com/imanyass/ShigaPass) | Distinguishing *Shigella*, enteroinvasive *E. coli*, and other *E. coli*, and predicting *Shigella* serotypes |
| [mlst](https://github.com/tseemann/mlst) | Multilocus sequence typing from assemblies |
| [Floc](https://github.com/DOH-JDJ0303/floc) | Iterative k-mer clustering for genomic surveillance |
| [LABEL](https://github.com/CDCgov/label) | Influenza segment, subtype, and clade assignment |
| [micromamba](https://mamba.readthedocs.io/en/latest/installation/micromamba-installation.html) | Installing the tools into self-contained environments |

## Databases and nomenclature

- [NCBI Pathogen Detection](https://www.ncbi.nlm.nih.gov/pathogens/): genomic surveillance data and SNP clusters for foodborne and healthcare-associated pathogens
- [PubMLST](https://pubmlst.org/): MLST schemes and allele databases for many species
- [EnteroBase](https://enterobase.warwick.ac.uk/): genomes and typing schemes for *Escherichia*, *Salmonella*, and related genera
- [ICTV](https://ictv.global/): official virus taxonomy
